# Digital Image Processing Project

A Python based project that demonstrates digital image preprocessing clustering and classification using machine learning techniques.

---

## Overview

This project focuses on practical implementation of image processing concepts.

You can

- Preprocess raw images
- Apply K-Means for image segmentation
- Train classification models
- Evaluate results

---

## Repository layout

classification  
modules/kmeans  
preprocessing  
app.py  
models.py  

---

## Technologies

- Python
- OpenCV for image processing
- NumPy for numerical operations
- scikit-learn for machine learning

---

## Setup

Clone the repository

git clone https://github.com/AhmedSaeed1234T/Digital-Image-Processing-Project.git

Enter project directory

cd Digital-Image-Processing-Project

Install dependencies

pip install opencv-python numpy scikit-learn

---

## Running the project

Run the main script

python app.py

The pipeline performs preprocessing then clustering or classification based on the code configuration.

---

## Modules description

preprocessing  
Loads images applies resize normalization and noise filtering

kmeans  
Performs pixel clustering for segmentation and feature extraction

classification  
Handles model training testing and prediction
